# 🏛️ El-cuartoDeGuerra

¡Bienvenido al repositorio del nuevo sitio web **El Cuarto de Guerra**! Este proyecto contiene la arquitectura lógica y backend de la aplicación.

## 🛠️ Tecnologías y Configuración Profesional

El desarrollo se enfocó en mantener un núcleo robusto e independiente del entorno de ejecución:

- **Lenguaje:** ☕ Java (Puro / Vanilla Java)
- **Gestión de Proyectos:** 📦 Apache Maven para la gestión limpia de compilaciones.
- **Portabilidad Avanzada:** 🚀 **Maven Wrapper (`mvnw`)** integrado. Permite la distribución e inicialización del proyecto en cualquier sistema de forma inmediata sin configuraciones previas ni instalaciones globales de Maven.
